## Fonctionnalités

- inscription et connexion ;
- déconnexion par session ;
- affichage et publication de messages ;
- persistance MySQL ;
- interface Bootstrap.

## Installation locale

Créer la base à partir du dossier bdd, adapter les identifiants dans connexion.php, puis servir le projet :

    php -S localhost:8000

Ouvrir ensuite http://localhost:8000.

Projet de formation conservé comme première étape avant la version MVC orientée objet mini-tchat-php-mvc.
